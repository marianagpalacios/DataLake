# Política de segurança

## Dados

Este repositório deve utilizar somente dados sintéticos ou públicos
adequadamente autorizados.

Não envie dados reais de pacientes.

## Credenciais

Não versione:

- arquivos `.env`;
- senhas;
- tokens;
- chaves privadas;
- credenciais de banco;
- credenciais de serviços externos.

## Vulnerabilidades

Ao identificar uma vulnerabilidade:

1. não publique credenciais ou dados sensíveis em uma issue pública;
2. descreva o componente afetado;
3. informe a versão;
4. inclua passos seguros para reprodução;
5. aguarde a análise antes de divulgar detalhes exploráveis.

## Escopo atual

A API é educacional e não possui autenticação.

Ela não deve ser exposta diretamente à internet como sistema de produção.

## Dependências

O repositório utiliza Dependabot para acompanhar atualizações de
dependências Python, GitHub Actions e Docker.
