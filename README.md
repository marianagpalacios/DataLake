# DataLake

Projeto de estudo inspirado na arquitetura de plataformas de integração de dados em saúde.

## Objetivo

Desenvolver uma pequena plataforma de engenharia de dados para consolidar conhecimentos em desenvolvimento de software, banco de dados e processamento de dados.

O projeto simula parte do fluxo de um Data Lake utilizado para integrar informações provenientes de diferentes fontes, realizando validação, armazenamento e disponibilização dos dados para consultas futuras.

O foco é aprender tecnologias amplamente utilizadas em projetos de pesquisa e inovação envolvendo Ciência de Dados, Engenharia de Dados e Bioinformática.
