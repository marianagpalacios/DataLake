# Changelog

Todas as alterações relevantes do DataLake são registradas neste arquivo.

## [Não publicado]

### Planejado

- autenticação e autorização;
- armazenamento de objetos;
- novos tipos de dados clínicos;
- suporte a novas fontes;
- observabilidade;
- processamento assíncrono.

## [0.8.0] — 2026

### Adicionado

- GitHub Actions;
- Ruff;
- build automatizado do pacote;
- validação da imagem Docker;
- artifacts de testes e cobertura;
- Dependabot;
- templates de Pull Request e issues;
- guia de contribuição;
- política de segurança;
- documentação final do portfólio.

## [0.7.0] — 2026

### Adicionado

- banco PostgreSQL exclusivo para testes;
- fixtures reutilizáveis;
- dependency override da API;
- testes de migrações;
- cobertura de linhas e branches;
- limite mínimo de cobertura.

## [0.6.1] — 2026

### Corrigido

- metadados de versão apresentados pela API.

## [0.6.0] — 2026

### Adicionado

- API REST com FastAPI;

- lineage;
- Swagger, ReDoc e OpenAPI;
- execução da API com Docker.
